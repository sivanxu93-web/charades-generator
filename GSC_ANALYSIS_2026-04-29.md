## Recommended SEO Roadmap

### P0: Fix broad generator CTR

Target pages: `/`, `/random-charades-generator/`

Actions:

- Rewrite homepage title/meta around exact head terms: "Charades Generator", "Charades Word Generator", "Random Charades Generator".
- Make the homepage H1 and first 100 words more exact-match for "charades generator" and "charades word generator".
- Add a compact above-the-fold "word generator" value prop: instant words, no login, copy/print, kids/adults/movie/Disney filters.
- Strengthen internal links from every themed page back to `/` with anchors such as "charades word generator" and "free charades generator".
- Reposition `/random-charades-generator/` as the exact answer for "random word generator for charades", not just a secondary themed page.

Expected effect: better CTR first, then ranking. This is the largest opportunity because broad/general queries have **31,993 impressions** but only **2.02% CTR**.

### P1: Build on the imposter cluster

Target pages: `/imposter-game/`, `/imposter-game-word-list/`, `/imposter-game/play/`

Actions:

- Create a stronger query path from "imposter game generator" to actual gameplay.
- Add a visible "Imposter Game Word Generator" section on `/imposter-game/`.
- Make `/imposter-game-word-list/` more list-first and snippet-friendly: headings for "Imposter Game Words", "Funny Imposter Words", "Easy Imposter Words", "Hard Imposter Words".
- Internally link between the generator, word list, and play page with exact anchors.

Expected effect: this cluster already has **14,768 impressions**. Position is close enough that focused content and internal links can move it.

### P1: Improve kids/family intent

Target page: `/charades-generator-for-kids/`

Actions:

- Update title/meta to include "kids charades generator", "charades for kids", and "children's charades generator".
- Add age-band sections near the top: ages 4-6, 7-9, 10-12.
- Add printable classroom and birthday-party language.
- Add internal links from classroom/family pages using exact kids anchors.

Expected effect: current page has **2,981 impressions** but only **42 clicks**. This is a relevance/snippet/ranking problem, not lack of demand.

### P1: Turn adult/funny into a ranking win

Target page: `/funny-charades-for-adults/`

Actions:

- Preserve current click appeal; the page has **8.91% CTR** despite position **19.33**.
- Add more long-tail sections: "funny charades for adults", "adult charades ideas", "hard adult charades", "office party charades".
- Link from homepage and random generator with adult/funny anchors.

Expected effect: ranking movement could compound quickly because CTR is already good.

### P1 Seasonal: Christmas page

Target page: `/christmas-charades-generator/`

Actions:

- Do not wait until December. Improve the page now, then refresh again in September/October.
- Add sections for "Christmas charades words", "Christmas movie charades", "family Christmas charades", and "kids Christmas charades".
- Add internal links from family, kids, Disney, and movie pages.

Expected effect: current off-season data is weak, but impressions exist. Seasonal pages need authority before demand spikes.

### P2: Decide what Pictionary is supposed to be

Target page: `/pictionary-word-generator/`

Actions:

- Either invest in it as a separate game vertical or de-prioritize it.
- Current position **54.57** suggests Google does not yet see the site as competitive for Pictionary.
- If investing, make it a real pictionary tool with category filters, drawing difficulty, printable lists, and Pictionary-specific FAQ/schema.
